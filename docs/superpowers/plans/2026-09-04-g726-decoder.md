# G.726 32 kbit/s Decoder Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship exact, reachable 32 kbit/s ITU-T G.726 Annex-A linear decoders for both registered nibble packings while keeping encoding explicitly unsupported.

**Architecture:** Replace `g726.rs`'s IMA-like stand-in with one fixed-width G.726 state machine derived from clauses 3–4, then adapt it through the existing `Machine<Frame>` wrapper with packet-continuous state. Registry metadata exposes only the two decoders; official Appendix-II code sequences and ffmpeg-produced raw streams are independent decode oracles.

**Tech Stack:** Rust 2024, `vaco-codec-core::SendReceive`, `vaco-frame` S16 audio, ITU-T G.726 (12/1990), Annex A (11/1994), Corrigendum 1 (05/2005), Appendix II (03/1991), ffmpeg 9.0.1 black-box fixtures.

- [ ] **Step 2: Implement clause-4 fixed-width blocks**

Implement private functions named for `RECONST`, `ADDA`, `ANTILOG`, `ACCUM`, `ADDB`, `ADDC`, `FLOATA`, `FLOATB`, `FMULT`, `UPA1`, `UPA2`, `UPB`, `LIMC`, `LIMD`, `FILTD`, `FILTE`, `LIMB`, `MIX`, `FILTA`, `FILTB`, `FILTC`, `LIMA`, `SUBTC`, `TRIGA`, `TONE`, `TRANS`, and `TRIGB`. Every intermediate is masked at the width printed by the standard; signed comparisons use explicit two's-complement conversion rather than Rust signed overflow.

The public-in-crate pipeline has this exact shape so all delayed fields update simultaneously from their old values:

```rust
impl DecoderState {
    #[must_use]
    pub(crate) fn decode_code(&mut self, code: u8) -> i16 {
        let code = code & 0x0f;
        let al = lima(self.ap);
        let y = mix(al, self.yu, self.yl);
        let (dqln, dqs) = reconst_32(code);
        let dq = antilog(adda(dqln, y), dqs);
        let (se, sez) = accum(self.a, self.b, self.sr, self.dq);
        let sr = addb(dq, se);
        let (pk0, sigpk) = addc(dq, sez);
        let tr = trans(self.td, self.yl, dq);

        let a2p = limc(upa2(pk0, self.pk[0], self.pk[1], self.a[0], self.a[1], sigpk));
        let a1p = limd(upa1(pk0, self.pk[0], self.a[0], sigpk), a2p);
        let mut bp = [0_u16; 6];
        for n in 0..6 {
            bp[n] = upb((dqs as u16) ^ (self.dq[n] >> 10), self.b[n], dq);
        }

        let yup = limb(filtd(wi_32(code), y));
        let ylp = filte(yup, self.yl);
        let fi = fi_32(code);
        let dmsp = filta(fi, self.dms);
        let dmlp = filtb(fi, self.dml);
        let tdp = tone(a2p);
        let ax = subtc(dmsp, dmlp, tdp, y);
        let app = filtc(ax, self.ap);

        self.a = [trigb(tr, a1p), trigb(tr, a2p)];
        self.b = bp.map(|value| trigb(tr, value));
        self.pk = [pk0, self.pk[0]];
        self.dq.rotate_right(1);
        self.dq[0] = floata(dq);
        self.sr = [floatb(sr), self.sr[0]];
        self.yu = yup;
        self.yl = ylp;
        self.dms = dmsp;
        self.dml = dmlp;
        self.ap = triga(tr, app);
        self.td = trigb(tr, tdp.into()) as u8;

        limo(sr) << 2
    }
}
```

```rust
pub(crate) fn decode(
    state: &mut DecoderState,
    data: &[u8],
    low_nibble_first: bool,
) -> Vec<i16> {
    let mut out = Vec::with_capacity(data.len().saturating_mul(2));
    for &byte in data {
        let pair = if low_nibble_first {
            [byte & 0x0f, byte >> 4]
        } else {
            [byte >> 4, byte & 0x0f]
        };
        out.extend(pair.map(|code| state.decode_code(code)));
    }
    out
}
```

### Task 3: Wire persistent decoder state and preserve refusal boundaries

**Files:**
- Modify: `crates/codec/vaco-codec-adpcm/src/lib.rs`

- [ ] **Step 1: Replace the decoder refusal wrapper**

Add `limits`, `state`, and `low_nibble_first` fields. On input, decode exactly two mono samples per byte and call `frame_from_samples` with `G726_SAMPLE_RATE`; on drain, finish the machine. Reset state in `flush`.

```rust
#[derive(Debug)]
pub struct AdpcmG726Decoder {
    machine: Machine<Frame>,
    limits: Limits,
    state: g726::DecoderState,
    low_nibble_first: bool,
}

impl SendReceive for AdpcmG726Decoder {
    type Input = Packet;
    type Output = Frame;

    fn send(&mut self, input: Option<&Packet>) -> Result<()> {
        match self.machine.accept(input.is_none())? {
            Accept::Drain => { self.machine.finish(); Ok(()) }
            Accept::Input => {
                let Some(packet) = input else { return Ok(()) };
                let samples = g726::decode(&mut self.state, packet.payload(), self.low_nibble_first);
                let frame = frame_from_samples(&self.limits, &samples, 1, G726_SAMPLE_RATE, packet.pts)?;
                self.machine.emit(frame);
                Ok(())
            }
        }
    }

    fn receive(&mut self) -> Result<Frame> { self.machine.receive() }

    fn flush(&mut self) {
        self.machine.flush();
        self.state = g726::DecoderState::default();
    }
}
```
