# Format coverage

GENERATED by `cargo xtask gen-coverage`. Do not edit.

Every container format Vaco registers, alongside every one the reference
implementation registers. Read it with
[why-some-formats-are-not-included.md](why-some-formats-are-not-included.md),
which explains what the notes mean.

The reference column is a list of *names* measured off `ffmpeg -demuxers`
and `-muxers`; see `xtask/data/reference-formats.txt` for the exact
provenance. A blank note means we match the reference for that format.

## Summary

| | Demux | Mux |
|---|---|---|
| Vaco | 176 | 118 |
| Reference | 359 | 183 |

Of the 413 format names either side registers, **214** are still to be
written and **1** is excluded by a decision record. The
ratio between those two numbers is the point of the other document —
nearly everything Vaco lacks, it lacks because nobody has written it yet.

Most of the excluded list does not appear above at all: capture and
playback devices are not in `-demuxers`/`-muxers` output, they are in
`-devices`. They are named in the other document.
